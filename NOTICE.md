# Third-party material

`LICENSE` (MIT) covers this repository's own code and copy. It does not cover
Mothership, which is © [Tuesday Knight Games](https://www.mothershiprpg.com/)
and is not distributed here. This project is not affiliated with Tuesday Knight
Games.

No Mothership text, tables, stat blocks, maps, handouts, or audio are in this
repository. The tool reads PDFs you own, on your own machine, and writes what it
extracts to a local cache that is gitignored and never published. The source
does contain a few game terms, such as stat and save names and the field labels
a parser searches for, because an extractor needs something to anchor on.
